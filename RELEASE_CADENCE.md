# Release Cadence

Quantum Idle follows a predictable weekly release rhythm so players and
contributors know when to expect updates:

- **Thursday @ 18:00 UTC** – Regular feature drops and UI polish
  (merged to `main` and deployed to GitHub Pages).
- **Monday @ 15:00 UTC** – Maintenance/hotfix window for regressions from
  the previous release.
- **Telemetry snapshots** – Session and prestige pacing data is reviewed
  every Thursday morning to validate the upcoming build.

What this means for changes in this repo:

- Batch non-critical work so it lands in the next Thursday release.
- Keep the maintenance window for critical fixes only.
- Include links to the live feedback channels in UI changes to keep the
  cadence grounded in player sentiment.

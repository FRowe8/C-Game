# Prestige Tree-Style Features for Quantum Idle

## What Makes Prestige Tree Addictive?

### 1. **Constant Progression Feel**
- Always something you CAN do (even if small)
- Multiple paths to progress simultaneously
- Short-term AND long-term goals visible
- Number go up dopamine

### 2. **Layered Complexity**
- Simple mechanics that layer together
- Each layer unlocks new systems
- Synergies between systems
- Automation that speeds up earlier layers

### 3. **Visual Clarity**
- Tree structure shows connections
- Color-coded unlocks/affordability
- Progress bars everywhere
- Immediate visual feedback

## 🎮 Prestige Tree Core Loop

What makes it addictive:
1. **See upgrade** → feels achievable
2. **Work toward it** → watch bar fill
3. **Buy upgrade** → satisfying click + visual feedback
4. **See new upgrades** → ooh, what's next?
5. **Repeat** → dopamine cycle

Current Quantum Idle is missing steps 1-2 (visible goals + progress bars).
